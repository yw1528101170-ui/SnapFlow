# SnapFlow (瞬流) v{VERSION} 发布说明

轻量、现代且高效率的 Windows 智能截图、贴图、屏幕性能监控与剪贴板增强工作流工具。

## 📦 发布包列表

| 文件名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `SnapFlow-Setup-v{VERSION}.exe` | 安装包 (推荐) | 现代向导式安装，支持桌面快捷方式、自启动配置与一键卸载 |
| `SnapFlow-v{VERSION}-win-x64-Portable.zip` | 绿色便携版 | 解压即用，仅在你主动开启自启动时写入一条注册表项 |
| `SHA256SUMS.txt` | 校验哈希 | SHA-256 完整性校验文件 |

## 🛠️ {VERSION} 修复与改进

- **依赖安全升级**：内置 SQLite 组件（SQLitePCLRaw）由 2.1.11 升级到 2.1.14，修复已知高危安全公告（GHSA-2m69-gcr7-jv3q）。

- **剪贴板隐私红线**：尊重密码管理器等工具在剪贴板上附带的「请勿收录」标记（`ExcludeClipboardContentFromMonitorProcessing`、`CanIncludeInClipboardHistory`、`CF_CLIPBOARD_VIEWER_IGNORE`，Windows 剪贴板工具的行业标准契约）。此前仅按前台进程名单过滤，名单外的密码管理器（以及复制后立刻切换窗口的时序绕过）会把一次性密码明文写进历史记录并被全文索引；现在带标记的内容整条跳过，且不会误伤普通复制。
- **AI 端点安全**：拒绝非本机的 `http://` 明文 AI 接口地址——此前 API Key 与整张截图会以明文出网（代理/网关日志可见）。本地推理服务（Ollama 等）仍可使用 `http://127.0.0.1` 或 `http://localhost`；设置页的「测试连接」同步执行该校验。
- **翻译隐私**：翻译文本改走 POST 请求体（不再出现在 URL 中，避免进入代理/网关日志）；翻译失败时不再把识别原文拼进浏览器地址栏打开网页版（避免进入浏览器历史）；开始翻译时明确提示文字将发送到 Google 翻译。
- **保存目录保留期**：「自动保存截图到本地」目录中的截图此前永不过期清理，含敏感信息的截图会无限期留存；现与历史记录使用相同的保留天数（仅清理本应用命名的文件，用户自行放入的文件不受影响）。
- **启动失败可感知**：初始化出错（如系统消息窗口注册失败）时弹出明确错误提示并退出，不再留下「无托盘、无热键」却占着单实例锁的空壳进程。
- **退出更快更稳**：退出时对后台任务（剪贴板入库、后台 OCR、保留期清理）的等待不再因 UI 线程被阻塞而必然超时，退出卡顿显著缩短，也不再出现「迟到的后台写入撞上已释放的数据库连接」导致的最后一条记录丢失。

## 🛠️ 1.1.3 修复与改进

- **卸载更干净**：卸载时会询问是否同时删除用户数据（历史记录、截图、贴图与设置，含 `%APPDATA%\SnapFlow`、`%APPDATA%\Jietu` 两个旧版本遗留目录）；默认保留，重装可找回历史。静默卸载（/SILENT、/VERYSILENT）不弹窗、自动保留数据。卸载结束后还会清扫安装目录的残留文件（修复杀毒软件实时扫描短暂锁定 DLL 导致的“卸载残留 123MB”问题）。
- **退出不留僵尸进程**：个别情况下退出/重启应用后进程残留（托盘消失但进程仍在、占用截图历史库、并导致下次卸载文件被锁）；现在 UI 退出后强制收尾，保证进程一定结束。
- **关于页版本号**：设置「关于」页此前硬编码为 1.1.0，与实际版本不符；现改为动态读取程序集版本，永不再过期。
- **版本号统一**：版本号唯一来源收敛到 `src/Jietu/Jietu.csproj` 的 `<Version>`；安装包、便携包、发布说明、随包说明与关于页显示全部由打包脚本自动同步。
- **工程清理**：移除开发机上的构建产物与本地工作记录目录（bin/obj、.workbuddy），并固化离线依赖包 SHA-256 校验清单。

## 🛠️ 1.1.2 修复与改进

- **安装时勾选开机自启不生效**：安装向导勾选「开机自启」只会写注册表 Run 键，而应用首次启动会按设置文件里的旧值（默认关闭）把这条自启项删掉，设置页也显示成未开启，必须手动再点一次。现在应用启动时会把注册表里的实际自启状态对账回 `settings.json`（同时修复被安全软件误删、升级换目录等情况），安装完成打开设置即可看到「开机自启」已开启。

## 🛠️ 1.1.1 修复与改进

- **稳定性**：修复「重启应用」必定留下后台僵尸进程的问题（单实例互斥体重复释放导致清理中断）；退出流程改为逐步容错并保证进程一定结束。
- **开机自启**：应用与安装包统一使用 `SnapFlow` 自启项，并自动清理旧版本残留的 `Jietu` 项；卸载时同步清理，避免删除程序后仍尝试启动旧 exe。
- **截图质量**：延时截图与长截图不会再把自己弹出的 Toast 提示胶囊截进成品图（提示窗口不参与抓屏 + 抓屏前等待退场动画结束）。
- **剪贴板**：剪贴板被其他程序短暂占用时，不再丢弃整张截图——仍会写入历史与保存目录，并给出明确提示。
- **隐私**：AI API Key 改为 Windows DPAPI 加密存储（同一账户才能解密），旧版明文配置在下次保存时自动升级；设置页隐私说明改为实事求是的「尽力过滤」。
- **设置健壮性**：设置文件损坏/半截时自动备份原文件并恢复默认；写盘失败会显式提示；保留天数输入改为防抖提交，清空或异常值不再触发误删历史。
- **快捷键**：录制 `Ctrl+Space`、`Alt+Tab` 等组合不再产生无法解析的配置（并兼容旧版 `0x20` 写法），也不会因一次误录锁死整页设置保存。
- **托盘**：Explorer 崩溃/重启后托盘图标会自动恢复（处理 `TaskbarCreated` 广播）。
- **数据目录**：迁移到 `%LOCALAPPDATA%\SnapFlow`，避免域漫游把历史库/截图/OCR 文本同步到服务器；旧目录数据会尽量保留迁移。
- **数据库**：启动时检测损坏并备份重建（`history.db.corrupt-<时间戳>`），不再出现“启动即沉默”；全文索引增加完整性校验。
- **抓屏兼容性**：桌面复制在空闲 3 秒后自动释放，不再长期独占导致 OBS/录屏/其他截图工具抓不到屏幕；最终 GDI 兜底不再返回全黑图；HDR 屏按系统 SDR 白点做色调映射。
- **标注一致性**：预览与导出的序号尺寸统一；马赛克笔画末点不再丢失、达上限时给出提示；绘制中按 Ctrl+Z 只撤销当前笔；点选区外不再误清全部标注。
- **工程**：源码树清理误建的 124MB 构建目录；NuGet 配置改用相对路径（仓库可移动）；打包脚本自动校验 exe 与安装包版本一致。

## 🚀 核心特性回顾

- **现代 Fluent Design 风格**：原生 Windows 11 / Windows 10 现代交互视觉，完美适配深浅色主题。
- **智能窗口与元素吸附**：精准捕获窗口边缘、控件边界，亦可自由拖拽像素级调整选区。
- **丰富标注工具箱**：内置矩形、圆形、箭头、自由画笔、荧光笔、文字、马赛克及步骤数字序号。
- **贴图置顶 (Pin)**：截图一键固定在屏幕最上层，多图对照、半透明穿透与缩放随心所欲。
- **屏幕性能监控悬浮窗 (OSD)**：极简 Fluent 置顶挂件，鼠标全穿透，实时监控 GPU/CPU/内存与网络速率。
- **离线 OCR 文字识别**：毫秒级提取截图中文字，支持即时复制与结构化文本提取。
- **屏幕放大镜与取色器**：实时显示像素坐标与 RGB / HEX 颜色值，按 `C` 键一键复制颜色。
- **滚动长截图**：支持网页、超长聊天记录与文档的连续无缝平滑拼接。
- **剪贴板历史管理**：快捷键 `Alt+V` 随时唤出近期复制的文本与图片，告别历史丢失。
- **单例保护与后台静默**：常驻右下角系统托盘，内存占用低，唤醒极速。

## ⌨️ 默认快捷键

| 操作 | 快捷键 |
| :--- | :--- |
| 区域截图 | `Alt + A` |
| 剪贴板历史 / 贴图唤出 | `Alt + V` |
| 复制光标处颜色 (取色器激活时) | `C` |
| 撤销上一步标注 | `Ctrl + Z` |
| 确认并保存到剪贴板 | `Enter` / 双击选区 |
| 取消 / 退出截图 | `Esc` |

> 快捷键可在软件“设置”界面中自由修改（右键托盘图标 → 设置）。

> 数据目录：`%LOCALAPPDATA%\SnapFlow`（历史库、截图缓存、设置文件；API Key 已使用当前 Windows 账户的 DPAPI 加密）。
