## 🛠️ {VERSION} 修复与改进

- **代码质量专项**：五大领域（密码库/截图链路/OSD 监控/剪贴板存储/基础设施）全面深度审查，逐项核实修复 24 项真实问题——包括密码库防抖保存管线加密头失效（编辑后保存失败并可能丢失数据）、修改主密码必失败、截图热键快速重入竞态（截图丢失 + 每次泄漏约 33MB 内存）、OSD 采样定时器重入与退出竞态、设置文件写入缺落盘保护（断电可致全部设置重置）、超长文本复制整条丢弃（改为截断入库）、AI 流式响应单分片解析失败丢弃整段回答等。
- **密码库条目编辑页重构**：新增条目类型（登录 / 安全备注）、实时密码强度提示（与密码体检同口径熵估算）、密码生成器（长度 8-64 + 字符类型 + 熵预览）、TOTP 两步验证密钥字段（Base32 即时校验）、取消未保存修改二次确认、详情页两步验证行。
- **回收站修复**：彻底删除此前因弹窗嵌套限制静默失败，改为行内两步确认（点击变红 → 3 秒内再点确认），不再嵌套弹窗。
- **解锁页修复**：密码输错时的错误提示条不再与卡片内容重叠（改为独立布局行）。
- **控件体系规范化**：全应用建立三层样式架构（画刷 → 基础层 → 窗口增量），输入框/卡片/键帽/徽章统一底座与圆角令牌，各窗口样式收敛为 BasedOn 增量。
- **全新应用图标**：扁平单色设计，品牌蓝纯色方圆底 + 白色层叠卡片与四芒星光（寓意快照堆叠与捕捉瞬间），9 个尺寸重新生成。
- **提示窗液态玻璃化**：接入与 OSD 同一套抓屏模糊引擎，磨砂玻璃胶囊实时折射背后桌面内容，失败自动回退不透明材质。
- **浏览器扩展权限最小化**：内容脚本从注入所有页面改为 activeTab 按需注入，攻击面收敛到用户点击的那一个页面。
- **工程质量**：单元测试扩展至 242 项，Release 构建零警告级收敛，关键异步路径（保存调度、采样回调、取消令牌）竞态全部闭环。

## 🌟 核心特性

- **智能选区截图**：窗口/元素自动吸附、放大镜与取色器、像素级微调；矩形/椭圆/箭头/画笔/荧光笔/文字/马赛克/聚光灯/Emoji/步骤序号标注。
- **贴图置顶 (Pin)**：截图钉在屏幕最前，可缩放、拖动、多图对照。
- **滚动长截图** 与 **延时截图**（1~10 秒）。
- **离线 OCR** 与 **二维码/条形码识别**。
- **AI 视觉对话**：多模态大模型，流式回答与多轮追问。
- **剪贴板历史**：`Alt+V` 唤出，文字与图像统一回溯。
- **本地密码库**：整库加密 + Windows Hello + 浏览器自动填充扩展。
- **屏幕性能监控 OSD**：GPU/CPU/内存/网络实时监控，鼠标全穿透。
- **Fluent Design** 深浅色自适应；自带 .NET 运行时，常驻托盘，开箱即用。

## ⌨️ 默认快捷键

| 操作 | 快捷键 |
| :--- | :--- |
| 区域截图 | `Alt + A` |
| 剪贴板历史 / 贴图唤出 | `Alt + V` |
| 密码库 | `Alt + P` |
| 复制光标处颜色 (取色器激活时) | `C` |
| 撤销上一步标注 | `Ctrl + Z` |
| 确认并保存到剪贴板 | `Enter` / 双击选区 |
| 取消 / 退出截图 | `Esc` |

> 快捷键可在软件「设置」界面中自由修改（右键托盘图标 → 设置）。

> 数据目录：`%LOCALAPPDATA%\SnapFlow`（历史库、截图缓存、设置文件；API Key 已使用当前 Windows 账户的 DPAPI 加密）。
