# 密码库实现偏差说明（PRD/设计 → 实际交付）

本页记录 `01-prd.md` / `02-design.md` 与最终实现（截至 v1.1.6）之间的有意偏差。
除本页列出的条目外，其余需求按文档交付；文档本身不改写，以这一页作为唯一的事实修正源。

## UI 精简（v1.1.6，bca719d 起）

密码库主界面做过一轮「减法」，方向是：日常 95% 的路径（列表 → 详情 → 复制/填充）一步到位，
低频维护功能收进「更多」菜单与对话框。被移除或未交付的 PRD 条目：

| PRD 条目 | 偏差 | 理由与现状 |
| :--- | :--- | :--- |
| UI-3/UI-4 桌面端生成器面板（词数滑块/熵显示/点击填入） | **未交付到桌面端** | 生成器保留在浏览器扩展 popup（16 位随机密码 / 6 词短语），桌面端创建流程自带实时强度计（熵估算 + 要求清单），足够覆盖「新建条目时想个密码」的场景。 |
| U1/SEC-01 生成器面板熵标签 | 同上 | `PasswordGenerator.PassphraseEntropyBits` 保留供测试与扩展口径使用。 |
| TOTP 验证器（编辑器 TOTP 字段 + 详情显示验证码） | **UI 移除，数据保留** | `VaultEntry.TotpSecret` 仍在模型/序列化/导入/体检里：导入的条目带密钥会完整保留（编辑保存时原样继承，不再清空），体检的「关键账号未开两步验证」维度依赖它；仅没有查看/复制验证码的界面。 |
| 笔记类型（Kind="note"）的创建入口 | **无创建入口** | 模型与列表/详情的显示分支保留（导入历史数据仍可读），但 UI 不再创建。 |
| 标签编辑 | **无编辑 UI** | 导入写入的标签参与搜索命中；编辑条目时原样继承，不增删。 |
| UI-9 删除后 6 秒撤销条 | 改为确认框 + 回收站 | 回收站（按天数/条数自动清理）承担可恢复性，撤销条的时效性收益不抵复杂度。 |
| UI-11 / 4.3 条目历史查看与回滚 UI | **后端交付，UI 未交付** | 每次保存记录最近 5 版（`VaultHistoryService`），回滚能力仅测试在用。 |
| UI-17 / Health.CriticalToggle 关键账号三态开关 | **未交付** | `CriticalOverride` 字段在载荷 v2 一次预留；体检按域名表自动判定关键账号，手动标记暂无入口。 |
| UI-5 左侧筛选区（体检/回收站入口 + 计数徽章） | 改为「更多」菜单对话框 | 与「偶尔打开一次」的使用频率匹配，不常驻挤宽度。 |
| 体检忽略（HealthIgnores「别再提醒」按钮） | **未交付** | 字段与 Normalize 清孤逻辑在 v2 载荷中预留。 |
| ClipboardClearSeconds 设置入口 | **无 UI** | 运行时恒用默认 30 秒（复制提示里展示），载荷字段已预留。 |

## v1 旧库处理（有意决策）

`VaultBlockKind.LegacyV1` 会话级阻断被移除：v1 容器格式从未随正式版发布（密码库自 v1.1.6
起首次对外），会话分类把 v1 文件按「未初始化」处理；真正创建新库时把旧文件改名留档
（`.v1-orphan-<时间戳>`），零覆盖、零删除。文件级分类（`VaultFileKind.LegacyV1`）与
v1 备份拒收（`BackupLegacyRefused`）保留。

## 桥协议

- 桥的 `lock` 命令已删除（扩展端从未发送过）；锁定入口是托盘菜单与密码库窗口。
- 审计日志（内存环形 200 条）已接入「设置 → 密码库 → 浏览器自动填充」的最近取用展示。
