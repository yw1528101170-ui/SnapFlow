# SnapFlow 密码库（Vault）+ 浏览器自动填充 实现计划

## 已确认的需求决策
- 范围：A 档「安全保险箱」+ B 档的浏览器自动填充（原生消息 + 自研扩展）
- 数据纯本地：不联网同步，备份靠加密导出文件
- Windows Hello 快速解锁进 MVP；TOTP 放 P1 一并做（本计划内完成）
- 存储走自定义加密容器（应用层加密），不用 SQLCipher、不做 KeePass 格式兼容
- AiApiKey 维持现有 DPAPI 方案不迁移（避免"库锁定时 AI 不可用"的耦合）

## 一、加密核心与文件格式（v1 规格）

**库文件**：`%LOCALAPPDATA%\SnapFlow\vault.spv`（AppPaths 加 `VaultFile`）

```
[8]  magic "SPVAULT\0"
[4]  version = 1 (uint32 LE)
[16] Argon2id salt
[4]  Argon2id iterations（默认 4）
[4]  Argon2id memoryKiB（默认 65536 = 64MiB）
[4]  Argon2id parallelism（默认 4）
[12] AES-256-GCM nonce
[N]  ciphertext = AES-GCM(payload JSON UTF-8) + [16] tag
```

- KDF：Argon2id，包 `Isopoh.Cryptography.Argon2`（MIT，与本项目 LICENSE 兼容，纯托管无原生依赖）；参数存头部、可升级
- 加密：.NET 内置 `AesGcm`（BCL，无新依赖）
- 明文 payload（仅内存）：条目数组（id/类型/标题/用户名/密码/URL/备注/标签/TOTP密钥/时间戳）+ 浏览器关联公钥表 + 库内偏好
- 写入原子性：tmp + `File.Move(overwrite)`，与 SettingsService 现有做法一致
- Hello 解锁：KeePassXC Quick Unlock 同款方案——`KeyCredentialManager.CreateAsync("SnapFlowVaultKey")`，对固定 32 字节 nonce 做签名，SHA-256(签名) 作为包裹密钥，加密「库主密钥副本」存 `hello.blob`；解锁时 Hello 弹窗→签名→派生→解包。失败一律回退主密码
- 错误尝试限速：UI 层指数退避（0.5s→1s→2s…封顶 30s）

## 四、浏览器自动填充（安全模型）

1. 扩展经原生消息连到 `SnapFlow.exe --native-messaging`（浏览器按注册表清单拉起），宿主进程仅做 stdio↔命名管道转发，不碰密码
2. 主程序的 VaultBridge 做准入控制：**首次连接必须在桌面端弹确认**（显示浏览器名/扩展指纹），关联公钥存入库内（加密落盘）；此后请求验签，未关联者一律拒绝
3. `get-logins(url)` 仅在**库已解锁**时返回匹配条目；锁定时扩展引导用户解锁（唤起主程序解锁窗）
4. 默认「新站点返回凭据需桌面端确认」，可关闭（信任后静默填充）
5. MVP 支持 Chromium 系（Chrome/Edge，MV3）；Firefox 结构差异大，本期不做（注册表清单预留）

## 五、分阶段执行（每阶段结束：编译过 + 全部单测绿）

1. **阶段 1｜加密核心**：VaultModels/VaultCrypto/VaultStore/PasswordGenerator/Totp + 全部单测（roundtrip、错密码必败、逐字节篡改必败、KDF 参数、RFC 6238 官方测试向量）
2. **阶段 2｜会话与 UI**：VaultSession/HelloUnlock/PasswordWindow/VaultUnlockWindow、AppHost/热键/托盘/设置页/剪贴板 SetTextSecret+自动清除/SensitiveForeground/防截屏接入
3. **阶段 3｜导入导出**：CSV 导入 + 加密导出 + 主密码修改（整库重加密、hello.blob 轮换）
4. **阶段 4｜本地桥**：VaultBridge + NativeMessagingHost + BrowserIntegration（注册表写删）+ 关联确认 UX + 单测（协议逻辑部分）
5. **阶段 5｜扩展**：ext/snapflow-vault 纯 JS MV3（内容脚本表单检测/填充、popup 选择器、后台 service worker），附 Edge/Chrome load-unpacked 手测清单

## 六、明确不做 / 风险边界
- 不做：云同步、KDBX 兼容、恢复码（后续可加）、Firefox 扩展、附件存储
- .NET 托管内存无法抗完整内存抓取——达到标准线即可：不落盘、不进日志、锁定即清、崩溃不落明文
- 密码明文永不进入：日志、剪贴板历史、截图、AI 上传路径（SensitiveForeground + 排除标记 + WDA 三重隔离）
- 新增 NuGet 仅 `Isopoh.Cryptography.Argon2`（MIT）；扩展零构建链（纯 JS），不进安装包、不进 CI
