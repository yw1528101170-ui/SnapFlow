## 🛠️ {VERSION} 修复与改进

- **本地密码库**：Argon2id + AES-256-GCM 整库加密，主密码只在本机、不上云；Windows Hello 指纹/PIN 快速解锁、空闲/锁屏/睡眠自动锁定；窗口防截屏，复制机密不进剪贴板历史并定时自动清除；加密备份与恢复、Chrome/Edge/Bitwarden CSV 导入、回收站（可恢复删除）与密码体检（弱密码/重复/长期未改/关键账号两步验证提醒）。
- **浏览器自动填充扩展**：随安装包分发的 Chrome/Edge 扩展（设置 → 密码库 → 一键安装），当前站点一键填充用户名密码、生成强密码；首次连接需桌面端人工确认，锁定时不返回任何凭据。
- **AI 视觉对话**：截图一键发给多模态大模型，流式回答、多轮追问、Markdown 渲染与全尺寸查看。
- **OCR 精度**：中文小字号识别基准提升（12px 中文识别率约 86.6% → 90.8%）。
- **设置页重做**：快捷键录制（Esc 取消/互斥禁用/呼吸光晕）、恢复默认热键、更清晰的功能分区。
- **安全加固**：浏览器集成开关逐请求生效；编辑条目保留导入的验证码密钥与标签（此前会被静默清空）；桥接通信按 UI 线程纪律取快照，消除并发撕裂风险。
- **OSD 监控精度**：CPU 实时频率、全协议网卡速率与 GPU 多卡（LUID 适配）重构，实测口径全面对齐任务管理器。
- **工程质量**：全量单元测试 227 项（含密码库加密容器/格式/导入导出/协议守卫/序列化往返与 OSD 指标逻辑），清理死代码与未用依赖面，浏览器扩展权限最小化（移除多余 tabs 权限）。
- **关于页与许可合规**：应用描述补上本地密码库；「开源许可」条如实列出 Apache-2.0 组件（SQLite/ZXing）与 EFF 词表（CC BY 3.0）的署名，第三方声明文件随包分发，关于页可一键查看。

## 🌟 核心特性

- **智能选区截图**：窗口/元素自动吸附、放大镜与取色器、像素级微调；矩形/椭圆/箭头/画笔/荧光笔/文字/马赛克/聚光灯/Emoji/步骤序号标注。
- **贴图置顶 (Pin)**：截图钉在屏幕最前，可缩放、拖动、多图对照。
- **滚动长截图** 与 **延时截图**（1~10 秒）。
- **离线 OCR** 与 **二维码/条形码识别**。
- **AI 视觉对话**：多模态大模型，流式回答与多轮追问。
- **剪贴板历史**：`Alt+V` 唤出，文字与图像统一回溯。
- **本地密码库**：整库加密 + Windows Hello + 浏览器自动填充扩展。
- **屏幕性能监控 OSD**：GPU/CPU/内存/网络实时监控，鼠标全穿透。
- **Fluent Design** 深浅色自适应；自带 .NET 运行时，常驻托盘，开箱即用。

## ⌨️ 默认快捷键

| 操作 | 快捷键 |
| :--- | :--- |
| 区域截图 | `Alt + A` |
| 剪贴板历史 / 贴图唤出 | `Alt + V` |
| 密码库 | `Alt + P` |
| 复制光标处颜色 (取色器激活时) | `C` |
| 撤销上一步标注 | `Ctrl + Z` |
| 确认并保存到剪贴板 | `Enter` / 双击选区 |
| 取消 / 退出截图 | `Esc` |

> 快捷键可在软件「设置」界面中自由修改（右键托盘图标 → 设置）。

> 数据目录：`%LOCALAPPDATA%\SnapFlow`（历史库、截图缓存、设置文件；API Key 已使用当前 Windows 账户的 DPAPI 加密）。
