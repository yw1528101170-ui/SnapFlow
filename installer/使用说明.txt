【快速上手】
1. 双击运行当前目录下的 SnapFlow.exe 即可启动软件。
2. 启动后程序常驻系统右下角托盘，并在后台监听快捷键。

【默认快捷键】
• Alt + A   : 启动区域截图（支持窗口自动吸附、选区微调、取色器、画笔标注、长截图）
• Alt + V   : 唤起剪贴板历史记录面板（支持图片与文本历史快速粘贴、搜索）
• Alt + P   : 打开/锁定本地密码库（首次进入引导创建）
• 按 C 键   : 截图选区或取色器激活时，复制光标处十六进制颜色值 (HEX)
• ESC 键    : 退出当前截图或关闭弹窗

【常用功能说明】
• 钉在桌面上（贴图）: 截图后点击工具栏「钉图」图标，将截图悬浮在最前。
• 离线文字识别 (OCR): 截图工具栏点击 OCR 按钮，快速提取图片中文字。
• 二维码识别: 截图工具栏点击二维码按钮，解析屏幕上的二维码/条形码。
• AI 视觉对话: 截图工具栏点击 AI 按钮，把截图发给多模态大模型提问
  （需先在 设置 → AI 视觉 中配置 API 端点与密钥）。
• 本地密码库: Alt + P 打开。整库加密保存在本机，不上传任何服务器；
  支持 Windows Hello 指纹/PIN 快速解锁、加密备份、CSV 导入、回收站与密码体检；
  复制的密码不进剪贴板历史，并会定时自动清除。
• 浏览器自动填充: 设置 → 密码库 → 浏览器自动填充，点「一键安装」把
  本目录 ext\\snapflow-vault 文件夹装入 Chrome/Edge，即可在登录页一键填充。
• 延时截图: 右键托盘图标 -> 延时截图 (1~10 秒)。
• 开机自启动与设置: 右键托盘图标 -> 点击「设置...」，可自定义快捷键、历史留存天数等。

【系统要求】
• 操作系统: 64位 Windows 10 (19041 及以上版本) 或 Windows 11
• 本便携版已内置完整依赖环境，无需额外安装 .NET 或运行时组件。
• 数据文件保存在用户本地目录: %LOCALAPPDATA%\SnapFlow
